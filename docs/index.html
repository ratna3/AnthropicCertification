MCP Chat

A powerful command-line and web interface for interactive AI chat using Google Gemini API with extensible tool integrations via the Model Control Protocol (MCP) architecture.

View on GitHub Get Started

Key Features

🤖

AI-Powered Chat

Interactive chat capabilities with Google Gemini AI models, supporting both command-line and web interfaces.

📄

Document Retrieval

Use @ symbol followed by document ID to include document content in your queries for context-aware responses.

⚡

Command System

Execute commands with / prefix, featuring auto-completion and extensible command definitions via MCP server.

🔧

Extensible Tools

Built on Model Control Protocol (MCP) architecture for easy integration of new tools and capabilities.

🌐

Web & CLI Interface

Choose between a beautiful web interface or a powerful command-line interface based on your needs.

🚀

Fast Setup

Quick setup with uv package manager or traditional pip installation, with comprehensive documentation.

Quick Setup

1

Clone Repository

Clone the project from GitHub

git clone https://github.com/ratna3/AnthropicCertification.git cd AnthropicCertification
2

Configure Environment

Set up your Gemini API key

# Create .env file GEMINI_API_KEY="your_api_key_here"
3

Install Dependencies

Install with uv (recommended) or pip

# With uv (recommended) pip install uv uv venv && source .venv/bin/activate uv pip install -e . # Or with pip python -m venv .venv source .venv/bin/activate pip install google-generativeai python-dotenv prompt-toolkit "mcp[cli]==1.8.0" fastapi uvicorn
4

Run the Application

Start the CLI or web interface

# Command-line interface python main.py # Web interface uvicorn simple_web_server:app --reload # Advanced web interface with MCP uvicorn web_server:app --reload

Prerequisites

  • ✅ Python 3.9+
  • ✅ Google Gemini API Key
  • ✅ Internet connection
